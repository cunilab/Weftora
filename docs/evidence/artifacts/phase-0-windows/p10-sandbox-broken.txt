P0-10: Windows Sandbox on this host is unusable
================================================

The plan was to run the export inside Windows Sandbox (WSB), which would have given a
genuinely Rust-free machine. WSB does not boot on this host, and the cause predates this
work.

Boot attempt result
-------------------
  Launching WindowsSandbox.exe with a valid .wsb: the UI process exits within ~10s and the
  mapped folder is never written. Hyper-V-Worker-Admin shows the VM starting then dying:

    id=18500 '36d607a1-...' started successfully.
    id=18515 '36d607a1-...' was shut down for a reset initiated by the guest operating system.

  Operator-visible dialog: "Windows Sandbox failed to initialize. The virtual machine or
  container exited unexpectedly. (0x80370106)"

  Documented cause for 0x80370106 with empty BaseImages: the base image is never staged,
  so there is nothing to boot. Recommended fix is a disable -> reboot -> enable -> reboot
  cycle. Reported by others too (microsoft/Windows-Sandbox#101, #112).

Workarounds tried, all ineffective
----------------------------------
  <VGpu>Disable</VGpu> in the .wsb   -- the most-upvoted fix in issue #101; no change.
  <Networking>Disable</Networking>   -- no change.

  Host GPU state, for the record (the #101 thread pins several cases on drivers):

    Intel(R) UHD Graphics                32.0.101.5768  (2024-07-24)
