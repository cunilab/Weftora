# Player interface font

Fira Sans Regular is embedded by the player for interface and dialogue text. Story fonts and localisation fonts override it. The developer value editor keeps Bevy’s monospace font.

Unmodified source: Bevy commit `b3bdd75becaffe9a16677cf5bae5bd6d198f052b`, `crates/bevy_feathers/src/assets/fonts/FiraSans-Regular.ttf`. Its SIL Open Font License is retained beside the font and in the release notice index under `bevy_text`. The existing `bevy_text` inventory entry is a collection anchor for both font notices, not an attribution of Fira Sans to that crate; recipient notices identify the actual asset source. No dependency on `bevy_feathers` is added.
